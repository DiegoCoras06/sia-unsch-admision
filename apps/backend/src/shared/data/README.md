# Ubigeos del Perú

ubigeo.json - 25 departamentos, 196 provincias y 1874 distritos con sus códigos INEI.

- **Fuente:** repositorio abierto [ernestorivero/Ubigeo-Peru](https://github.com/ernestorivero/Ubigeo-Peru) (json/ubigeo_peru_2016_*.json), basado en la codificación del INEI, versión 2016.
- **Descargado y validado:** 25/10/2026 (códigos de 2/4/6 dígitos, sin caracteres sospechosos, Ayacucho completo).
- **Limitación:** no incluye los distritos creados después de 2016; si un postulante no encuentra el suyo, elige el distrito del que se separó.
- Copia idéntica en pps/frontend/public/data/ubigeo.json (selectores) y pps/backend/src/shared/data/ubigeo.json (validación).
